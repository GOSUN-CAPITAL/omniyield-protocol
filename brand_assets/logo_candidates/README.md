# OmniYield Protocol & GSA 官方品牌标识候选库 (Logo Candidates)

本文档归档并索引 OmniYield Protocol (GSA) 的全套官方品牌视觉候选方案。所有高分辨率图片与矢量源文件均统一存放在本目录及前端静态资源目录中。

---

## 🎨 方案概览与设计哲学

### 方案 1：莫比乌斯全链之盾 (The Mobius Shield)
* **设计构思**：以双层交织的翡翠青莫比乌斯环环绕中央六边形主权金库盾牌，点缀全天候黄金光晕。
* **象征寓意**：象征 16 链跨链资产的无休止生息流动与穿透式安全防护。
* **适用场景**：大型黑客松海报、官网主视觉 KV、全景架构封面。
* **文件路径**：
  - `brand_assets/logo_candidates/option_1_mobius_shield.png` (516 KB)
  - `brand_assets/logo_candidates/option_1_mobius_shield.jpg`

### 方案 2：极简主权金库三棱镜 (The Sovereign Vault Prism)
* **设计构思**：对标 Morpho / BlackRock 极简数学美学，以纯粹干净的等轴测几何立方金库为底，顶部被向上 45 度的切割面利落分开。
* **色彩风格**：纯黑曜石底色 + 电光翡翠绿 (#00FFA3) 与白金刻面，极具华尔街资管质感。
* **象征寓意**：绝对隔离的金库安全性与向上持续复利的收益跃迁。
* **文件路径**：
  - `brand_assets/logo_candidates/option_2_vault_prism.png` (337 KB)

---

### 方案 3：极简“G”字母超级符号 (Minimalist G-Monogram)
* **设计构思**：经典现代科技金融超级符号，一笔成型的几何大写“G”，向内贯穿形成金库主横梁（Vault Keystone），右上角点缀科技焦点。
* **色彩风格**：高饱和电光青绿渐变 + 纯白横向主轴。
* **象征寓意**：GOSUN（高盛主权资产）的核心品牌辨识度，强力聚合流动性并锁固主权收益。
* **适用场景**：16x16 浏览器 Favicon、App 手机图标、极小尺寸头像。
* **文件路径**：
  - `brand_assets/logo_candidates/option_3_minimal_g_monogram.png` (98 KB)
  - `brand_assets/logo_candidates/option_3_minimal_g_monogram.svg` (矢量原稿)

### 方案 4：中华河图洛书·九宫天平矩阵 (Hetu-Luoshu Sacred Matrix)
* **设计构思**：源自东方远古文明的数学与宇宙秩序之源——**河图洛书（戴九履一，左三右七，二四为肩，六八为足，五居中央）**。
* **数学与资管映射**：
  - **纵横十五·动态守恒**：九宫矩阵无论横、竖、斜相加皆为 15，完美暗合资管金库**“代币差额守恒（Token Diffs）与达里奥全天候四维平价（Risk Parity）”**的绝对数学平衡！
  - **中五为尊·主权金库**：中央为代表中央土德的**耀目金核（Sovereign Vault 5）**，统领四维八极之流动性。
  - **天圆地方·气韵流转**：外方内圆的青玉能量环连接九大星宿节点，代表 16 链意图网络围绕 NEAR 中枢的生生不息。
* **文化底蕴**：东方数理哲学与现代全链密码金融的完美融合，极具史诗感与全球独创辨识度！
* **文件路径**：
  - `brand_assets/logo_candidates/option_4_luoshu_matrix.png` (182 KB · 1024x1024 高清)
  - `brand_assets/logo_candidates/option_4_luoshu_matrix.svg` (矢量原稿)
