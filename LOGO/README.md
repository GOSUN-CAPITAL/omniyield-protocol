## 🔄 双向兼容与自动同步机制

1. **向后兼容性**：
   前端 `frontend/public/logos/` 中既保留了原有根目录文件（如 `/logos/btc.svg`），又创建了四级分类子目录（如 `/logos/crypto/btc.svg` 和 `/logos/wallets/metamask.svg`），历史代码调用与新架构完全无缝兼容。
2. **替换或新增图标指南**：
   - 替换某种币种或股票：只需将新的 SVG/PNG 放入对应分类子目录下（如 `LOGO/crypto/btc.svg` 或 `LOGO/wallets/okx.svg`）；
   - 前端对应静态路由将立即生效，刷新页面即可查看最新官方高保真效果！
